DAY 11 - PROMPTS TO PASTE (Claude Code in VS Code, inside the docker-practice folder)
Short and plain on purpose. Claude's wording changes every run. Check the result with real commands.
All data is made up, including the secrets. Never put real passwords in a Dockerfile or .env.

===== 0. SETUP =====
Unzip docker-practice.zip, start Docker Desktop, open the folder in VS Code.
Terminal: docker --version   and   docker ps
Before class (so downloads are ready):
docker pull ubuntu:latest
docker pull python:3.12-slim
If port 5000 is busy, use 5001:5000 and open localhost:5001.

===== 2. BUILD THE BLOATED IMAGE (terminal) =====
docker build -t shop-status:bloated .
docker images
docker run -d --name bloated -p 5000:5000 shop-status:bloated
curl localhost:5000

docker exec bloated ls -a /app
docker rm -f bloated
