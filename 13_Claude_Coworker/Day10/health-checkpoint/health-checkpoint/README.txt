health-checkpoint: a small practice project (all data is made up)

THE GOAL
  Build your own "daily server health report": one script that reads
  a disk report and an app log and prints a short, readable summary.

WHAT IS IN THIS FOLDER
  sample/df.txt    a saved copy of the "df -h" disk report
  sample/app.log   a saved copy of an app log

Why sample files? On a real server the script would run df and read the
real log. Sample files make it work on every laptop, including Windows.

RULES
  1. Nothing here is real. Never paste real logs or passwords into Claude.
  2. Read what Claude writes before you run it.
