# DevOps Engineering Knowledge

A personal, searchable knowledge base for training material, practical labs, verified troubleshooting notes, projects and interview preparation.

## How to use
- Keep original training handouts in `00_Training_Materials`.
- Convert useful lessons into concise Markdown notes in the relevant topic folder.
- Record troubleshooting as symptom, impact, diagnosis, root cause, fix and verification.
- Test commands in a lab before marking a solution as verified.
- Never commit passwords, tokens, private keys, customer data or production logs containing sensitive information.
